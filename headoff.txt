- الاستضافة: Cloudflare Pages
- قاعدة البيانات: Cloudflare D1 (مجاني)
- النشر: GitHub Actions → Wrangler CLI (deploy.yml موجود بالفعل)
- SSH: عبر GitHub Actions (وليس داخل Cloudflare Worker)
- الذكاء الاصطناعي: OpenRouter
- المصادقة: JWT يدوي
- لا يوجد package.json في الجذر — المشروع Cloudflare Pages بحت
- لا يحتاج npm install / npm run build

الملفات الرئيسية في المشروع

Root:
- wrangler.toml → إعدادات Cloudflare Pages + D1
- .gitignore → تجاهل node_modules/.env/.wrangler
- README.md → وصف مختصر

frontend/:
- index.html → صفحة الترحيب
- dashboard.html → لوحة التحكم الرئيسية (3729 سطر)
- test-auth.html → صفحة تسجيل الدخول

functions/api/:
- auth/login.js → تسجيل الدخول + JWT
- auth/me.js → التحقق من الجلسة
- auth/register.js → التسجيل (مغلق)
- sites/index.js → CRUD للمواقع
- sites/read.js + read/start.js + read/result.js → قراءة ملفات
- sites/write.js + write/start.js → كتابة ملفات
- sites/ssh-test.js + ssh-test/start.js → اختبار SSH
- sites/git-status.js + git-status/start.js → git status
- sites/git-commit.js + git-commit/start.js → git commit
- sites/backups.js → النسخ الاحتياطي
- chat.js → شات AI
- ai-diagnose.js → تشخيص AI
- health.js + health-check.js + health-check-all.js → Health Checks
- dns-check.js → فحص DNS
- tls-check.js → فحص TLS
- settings.js → إعدادات المستخدم

.github/workflows/:
- deploy.yml → النشر التلقائي
- ssh-test.yml → اختبار SSH
- ssh-read.yml → قراءة ملفات
- ssh-write.yml → كتابة ملفات (مع mkdir -p)
- ssh-git-status.yml → git status
- ssh-git-commit.yml → git commit

migrations/:
- 0001-0010 → بنية قاعدة البيانات (users, sites, sessions, tasks, logs, backups, ssh_requests)

executor/:
- server.js → خدمة SSH منفصلة (Express + ssh2)
- package.json → تبعيات executor
